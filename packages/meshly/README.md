# meshly

```bash
npm install -g meshly
meshly init
meshly doctor
meshly run
meshly dev
```

The operating system for autonomous workers.

Agents reason. Meshly governs execution. Solari provides the environment.

`meshly init` requires a Solari API key. Meshly will not pretend live infrastructure ran.
